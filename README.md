# So sanh laptop gaming — tong sap

Trang tinh (mot file `index.html`): bang tong sap laptop gaming da khao gia, xep theo diem can doi
cua 4 tieu chi — suc manh tong, suc manh lam viec, dang tien (trieu dong / 1 diem), bao hanh.

- GPU cham diem theo PassMark G3D Mark, moc RTX 5060 Laptop = 100.
- CPU cham diem theo Cinebench R23 (trung vi Notebookcheck), moc i7-14650HX = 100.
- Loc duoc theo GPU, RAM, nguon ban, muc gia; bam tieu de cot de sap xep; in A4 ngang vua 1 trang.

Ten nguoi ban ca nhan tren Facebook da duoc viet tat (vi du `FB "H.K."`) — ban day du giu rieng,
khong dua len day.

So lieu la ghi chep ca nhan tu tin rao ban, co the sai hoac da cu. Khong phai tu van mua hang.
